Recipe Finder Application
At its core, the app solves a simple problem:

 “What can I cook with what I already have?”
 
You input ingredients, and the app returns relevant recipes, ranked by how well they match.

Features
🔍 Ingredient-Based Search:
Users add ingredients as tags

The app queries the Spoonacular API

Returns recipes that:

1. Maximize ingredient usage

2. Minimize missing items
🧾 Recipe Results:
Each recipe card shows:

Image

Title

✅ Used ingredients count

⚠️ Missing ingredients count

This helps users quickly judge feasibility

📊 Sorting System
Two ranking modes:

Best Match → uses most of your ingredients

Fewest Missing → needs fewer extra items

🥗 Diet Filters
Users can choose:

Vegetarian
Vegan
Gluten-Free
Keto / Paleo
